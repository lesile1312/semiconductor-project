# 外部数据源筛选与背景说明

核对日期：2026年9月24日

本次核对覆盖实验室的[原创数据库](https://riskalab-databank.vercel.app/databases)、[风险数据库](https://riskalab-databank.vercel.app/risk-databases)、[冲突数据库](https://riskalab-databank.vercel.app/conflict-databases)与[经典数据集库](https://riskalab-databank.vercel.app/library)。筛选标准是能否补足“中美科技竞争—第三方半导体节点—中国企业供应链”的某个明确环节，不以数据库数量作为目标。

## 筛选与排除记录

本表用于说明数据源的适配性筛选，不代表这些来源都已接入作品。当前网页只展示进入核心指标的数据；下列未接入来源保留在本文件和来源登记表中，供审计筛选过程。

| 数据源 | 与项目的关系 | 本轮处理 |
|---|---|---|
| GDELT US-China Bilateral Events | 中美双边宏观事件资料，不是第三方经济体的半导体贸易或企业受限记录。 | 本轮未取得可复现的事件级明细，未用于背景预警、国家分值或网页功能；仅保留筛选记录。 |
| Global Trade Alert（GTA） | 目录字段包括实施方、受影响经济体、HS商品范围及政策日期；可用于后续筛选半导体相关政策。 | 本轮未取得并清洗事件级原始记录，未接入网页、未报告半导体事件数，也不进入总分。 |
| US Consolidated Screening List（CSL） | 个体、企业或船只层级的受限主体登记，理论上可核查真实供应商、客户或关联方。 | 本轮没有真实企业名称和经确认的历史名单快照，未生成匹配结果或国家风险值，也未将其展示为已接入功能。 |
| IMF PortWatch | 2019年至今记录主要海上咽喉的每日船舶通行数；数值不是贸易额、吨位或半导体货流。 | 不用于2017回测或国家总分。只有取得企业设施和运输路线后，才适合做运营连续性补充。 |
| UCDP/PRIO、ACLED等冲突与政治暴力数据 | 记录武装冲突、抗议或政治暴力，可用于具体厂区、港口的安全与连续经营评估；与技术出口管制不是同一测量对象。 | 本项目没有设施位置与企业路线样本，故不纳入核心指标或地图。 |

## 其他未选来源

- 风险数据库中的 OECD TiVA、UN Comtrade、ATOP 与 UNGA 数据已分别用于价值链、HS8542贸易、联盟和投票理想点指标；不重复引入相同或更宽口径的汇总项。
- 风险数据库中的PRISM、FDIRRI反映外国投资审查或准入限制，不等于半导体技术出口管制；部分数据的国家覆盖与本项目12个经济体不完全一致，因此暂不并入这轮比较。
- 经典数据集库中的战略竞争/对抗关系数据最后观测年份止于2020，不能直接提供2022状态；宽口径地缘政治风险序列也不能替代企业或HS8542层面的暴露测量。
- 原创库中的全球钴供应链研究对象是钴，且时间止于2019；方法上可作参考，但不作为半导体供应链观测数据。

## 解释边界

总览页新增说明区用于区分宏观背景、政策措施、受限主体与现场运营风险。目录页提供的事件数和时间范围是数据库覆盖信息，不是本研究的发现。只有拿到可审计的原始记录、明确匹配单位和时间口径，并完成人工复核后，候选来源才可能成为独立的企业筛查或政策扫描模块；本说明不改变GTRI核心面板、权重或排名。
