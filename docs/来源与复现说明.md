# 芯链哨兵｜来源与复现说明

本文件把提交包中的数据名称、来源层级和复现口径放在一起，方便评委在不依赖开发环境的情况下核对项目边界。提交包提供清洗后的面板、指标结果、验证脚本和本说明；临时原始 API 响应不作为附件打包。

## 1. 主办方基础数据（指数的三项基础库）

以下三项均来自北京大学全球风险政治分析实验室数据智能平台风险数据库页面：

| 数据集 | 在项目中的用途 | 年份/覆盖边界 |
| --- | --- | --- |
| UNGA Voting Ideal Points | 构造 P1：样本经济体相对中国与美国的投票位置 | 以目标年为中心的三年窗口，用于结构性比较 |
| ATOP v5.1 | 构造 P2 的历史正式联盟状态 | 公开状态覆盖到2018年；2017使用对应观察值，2018状态保留作交叉资料 |
| OECD TiVA 2025 | 构造 N1：C26_27电子产业的外国增加值占出口比重 | OECD TiVA 2025版 |

目录核验入口：
`https://riskalab-databank.vercel.app/risk-databases`

## 3. 贸易查询口径

- Reporter：研究国自报，不用中国出口或美国进口的镜像流量替代。
- 年份：2017、2022。
- 商品：HS 8542，四位编码；跨年保持同一层级。
- Flow：Imports、Exports。
- Partner：全部伙伴；清洗时删除 World 和地区汇总项，只保留真实伙伴记录。
- 贸易值：使用官方响应中的贸易值字段；N2、N3为份额，N4=N2×N3，V1为进口伙伴份额平方和，V2为进口占比达到1%的伙伴数。

## 3.1 地图底图口径

网页地图使用 Natural Earth 1:110m Admin 0 Countries 公有领域国家轮廓。项目从工作区的 `原始数据/底图/ne_110m_admin_0_countries.geojson` 提取低分辨率几何，压缩为 `网页/assets/polygon-map-data.js`，用经度—纬度的等距圆柱投影绘制。节点数值仍来自核心面板，地图轮廓只承担地理定位功能，不用于领土或边界法律判断。鼠标悬停和 Tab 键聚焦都会显示同一张指标卡。

地图视觉层另外把可匹配的11个研究经济体轮廓单独着色：2022年 N4 达到0.05及以上的节点使用暖红色，其余节点使用青色；当前选中节点会提高边框亮度。地图两端增加两个分析锚点：青色虚线表示“中国投入 → 第三方节点”，琥珀色虚线表示“第三方节点 → 美国市场”。连线的透明度和线宽由对应节点的 N2、N3 调整，用来表达指标结构，不是实际运输路线，也不表示因果关系。新加坡在 Natural Earth 1:110m 低分辨率要素中没有可稳定分离的独立面，因此使用与节点对齐的菱形微型标记，避免用邻近大国轮廓代替新加坡。

## 4. 运行验证

在提交包的 `05_方法与验证` 文件夹中运行：

```text
python 重算敏感性诊断.py
```

脚本会读取同目录的核心面板与试点指数，检查主键、N4乘积、范围、2022 P2补充覆盖和敏感性诊断。输出应与 `指标验证报告.md` 中的15项检查一致。由于本提交包不包含临时 API 响应，重新抓取时应按本文件的参数重新请求官方接口，并把新的原始响应另行保存，不要直接覆盖已提交结果。

## 5. 重要边界

P3目前完成的是候选规则筛选和定向人工核对，尚未完成覆盖实体、产品范围、例外条款与第三方企业路径的逐条法律复核。因此网页和报告都把 P3 放在独立证据层，不把它冒充成国家级法律分数，也不把“未匹配到事件”解释为“没有法律风险”。

2017与2022的 P1 使用中心三年窗口，适合做结构性对照，不应被理解为严格的无前视预测回测。P2的2022补充来自官方结构清单，不能替代同源、逐年动态联盟数据。
