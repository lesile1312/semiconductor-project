## 3. 贸易查询口径

- Reporter：研究国自报，不用中国出口或美国进口的镜像流量替代。
- 年份：2017、2022。
- 商品：HS 8542，四位编码；跨年保持同一层级。
- Flow：Imports、Exports。
- Partner：全部伙伴；清洗时删除 World 和地区汇总项，只保留真实伙伴记录。
- 贸易值：使用官方响应中的贸易值字段；N2、N3为份额，N4=N2×N3，V1为进口伙伴份额平方和，V2为进口占比达到1%的伙伴数。

## 3.1 地图底图口径

网页地图使用 Natural Earth 1:110m Admin 0 Countries 公有领域国家轮廓。项目从工作区的 `原始数据/底图/ne_110m_admin_0_countries.geojson` 提取低分辨率几何，压缩为 `网页/assets/polygon-map-data.js`，用经度—纬度的等距圆柱投影绘制。节点数值仍来自核心面板，地图轮廓只承担地理定位功能，不用于领土或边界法律判断。鼠标悬停和 Tab 键聚焦都会显示同一张指标卡。

地图视觉层另外把可匹配的11个研究经济体轮廓单独着色：2022年 N4 达到0.05及以上的节点使用暖红色，其余节点使用青色；当前选中节点会提高边框亮度。地图两端增加两个分析锚点：青色虚线表示“中国投入 → 第三方节点”，琥珀色虚线表示“第三方节点 → 美国市场”。连线的透明度和线宽由对应节点的 N2、N3 调整，用来表达指标结构，不是实际运输路线，也不表示因果关系。新加坡在 Natural Earth 1:110m 低分辨率要素中没有可稳定分离的独立面，因此使用与节点对齐的菱形微型标记，避免用邻近大国轮廓代替新加坡。

### 3.2 地图动效口径

网页采用三种有限动效模式：`tilt-panel` 让地图面板随指针产生不超过约5.5度的空间倾斜；`glow-border` 用低透明度的边缘光标出交互面；`spring-cascade` 让少量高暴露连线上出现错峰移动的信号粒子。世界轮廓先被预计算为4.8—7.2像素间距的点阵，再叠加86个（窄屏52个）本地确定性空间粒子；深度值只改变尺寸、透明度和指针视差，不改变任何指标。动效只在地图处于视口且页面可见时运行，使用单一 `requestAnimationFrame`；开启 `prefers-reduced-motion` 时保留静态点阵地图、国家轮廓、标签和键盘访问，关闭倾斜、流光和移动粒子。

## 4. 运行验证

在提交包的 `05_方法与验证` 文件夹中运行：

```text
python 重算敏感性诊断.py
```

在公开网站仓库根目录运行 `python scripts/06_build_master_panel.py`、`python scripts/32_build_multisource_integration_audit.py`，依次重建核心面板、字段级血缘、数据源覆盖表和多源连接检查；再运行 `python scripts/build_public_assets.py`，可重建网页数据；随后运行 `python scripts/build_portable_site.py` 生成三个自包含页面。数据源逐项校验记录见 `data/多源数据整合检查.csv`（15项），主表字段血缘见 `data/字段级来源血缘.csv`（46列），按目标年整理的数据源覆盖见 `data/各年份数据源覆盖.csv`（22条）；指标与样本质量检查见 `docs/指标验证报告.md`（16项）。这些检查用于确认数据结构、来源链接和规则执行，不代表指数准确率。CDIS工作簿置于 `data/raw/fdi/`，文件哈希列于来源登记表。Comtrade原始接口响应不全部随在线展示仓库打包；重新抓取时按查询口径另存新快照，不能覆盖既有文件。

## 5. 重要边界

P3已对所选10条候选规则逐条做范围核对，但这不是对BIS全部规则的穷尽法律审查，也没有连接全部受规制实体、产品例外及具体企业交易路径。网页与报告因此把P3放在独立证据层，不把它冒充为国家级法律分数；零值仅表示本次选定复核集合未记到命中，不等于没有法律风险。

2017与2022的 P1 使用中心三年窗口，适合做结构性对照，不应被理解为严格的无前视预测回测。P2按目标年使用2017 ATOP观察值与2022官方结构安排编码，来源不同，不是同源时间序列；ATOP 2018结构状态只作为单独参照。CDIS目标年2022映射的是2021观测，必须保留滞后标记。

### 3.3 视觉与触控层

网页视觉层采用深色数据舞台、点阵世界轮廓、低透明度网格和局部信号光，不把装饰粒子当作数据。地图使用 Canvas 2D 绘制，CSS 负责有限的 3D 透视和焦点光；总览页与风险迁移页共用同一套粒子、节点和连线逻辑。地图容器保留纵向页面滚动，节点按钮为 44px 触控区域，并提供 Tab 聚焦路径。开启 `prefers-reduced-motion` 时，地图回落为静态轮廓、标签和指标卡，避免动效影响阅读。

### 3.4 移动端首屏绘制修复

部分手机浏览器和在线预览代理会先完成文字与样式布局，再异步确定地图容器高度。旧版脚本若在这个短窗口内读取到过小的容器尺寸，Canvas 会跳过首帧绘制，随后页面尺寸虽已稳定却没有再次触发重绘，于是出现“文字正常、地图空白”的现象。现版使用 `requestAnimationFrame` 统一安排重绘，并由 `ResizeObserver`、屏幕方向变化和 `visualViewport` 变化触发重新适配；进入页面后另设 120ms 与 420ms 两次兜底重绘。该修复只改变绘制时机与画布尺寸适配，不改变数据、指标和地图视觉含义。窄屏本地验收结果：地图点阵、国家轮廓、节点标签均可见，浏览器错误/警告为空。

### 3.5 页面动效增强

三页共用同一套轻量视觉层：首屏扫描光束用于提示地图是可探索的，顶部能量线反映滚动位置，卡片局部光场和 3D 微倾斜用于回应指针位置，按钮按下反馈用于确认触控。地图容器不再叠加页面级 perspective，地图本体只保留一层有边界的弹簧倾斜；Canvas 适配读取未变换的布局尺寸，避免 ResizeObserver 把透视后的外接框反复写回而造成首屏持续放大。动效由单一 `requestAnimationFrame` 合并指针与滚动更新；触控设备不强制倾斜，`prefers-reduced-motion` 下保留信息层级并关闭扫描、倾斜和入场动画。效果只改变展示层，不改变面板数值、国家选择器和企业扫描规则。
