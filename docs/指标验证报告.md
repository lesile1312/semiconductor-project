# 芯链哨兵指标验证说明

这份说明记录本轮数据核验的结果。它回答的是“数据能不能复算、口径有没有混用”，不把内部检查包装成预测准确率。

## 一、核验安排

核验分为三步：一是用马来西亚和越南的人工基准值做外部对照；二是检查公式、范围、主键和面板完整性；三是比较2017和2022年各国排序，观察结构是否发生变化。2022年的P2已经用美国国务院公开的集体防御安排和北约成员名单补齐，ATOP 2018状态作为交叉资料保留，不把它当作2022年的动态观测。

下表是同一批12个经济体的跨年排序相关。它用于描述结构稳定程度，不是统计意义上的可靠性系数。

P1的国家排序最稳定，N4和V2变化更大。这与研究预期一致：政治位置不会在五年内频繁翻转，但贸易通道和可替代来源会随产业布局变化。需要注意，P1采用目标年中心三年窗口，因此本节是结构性对照，不把它解释成严格的无前视历史回测。

2022年N4较2017年上升的国家有8个、下降的国家有4个。墨西哥仍是样本中双重依赖最高的节点，但它的N4已经下降，因此不能把“最高”直接写成“持续上升”。

## 五、口径与边界

- 所有贸易指标都使用研究国自报的UN Comtrade HS8542四位数据；清洗时去掉World和地区汇总项，只保留真实伙伴国。
- P3候选法律事件已完成机器筛选和定向人工核对，但尚未完成覆盖实体、产品范围及例外条款的逐条法律复核；目前仍作为待复核的政策证据和预警线索，不把实体级规则直接外推成国家分数。
- 2017与2022的归一化把24条观测合并后做样本内min-max处理，V2先取反向值。分数表示样本内相对位置，不是跨样本的绝对风险概率。
- 这份验证不替代企业内部供应商、客户和BOM核查，也不构成法律或投资意见。
