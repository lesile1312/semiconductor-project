# 多源数据整合复现说明

本说明对应仓库内的离线数据包。复现过程先连接已经归档并完成单源处理的中间表，不要求现场申请账号或重新下载；若要重抓原始来源，需按各官方接口当前规则逐项复核。

## 三分钟复现路径

在项目根目录安装依赖并运行：

```powershell
python -m pip install -r requirements.txt
python scripts/06_build_master_panel.py
python scripts/32_build_multisource_integration_audit.py
python scripts/build_public_assets.py
python scripts/build_portable_site.py
```

第一步把贸易、UNGA、ATOP、TiVA、BIS人工范围核对摘要、IMF CDIS背景表按 `country + ISO3 + year` 合并；第二步重新生成来源登记、SHA-256清单、46字段来源血缘、22条来源—目标年覆盖记录与15项来源连接检查；最后两步刷新网页数据和三个离线单文件页面。预期输出为24行国家—年份主表；另运行 `scripts/13_descriptive_and_validation.py` 可重建16项测量数据/公式检查。这两类检查均不是指数准确率、因果效度或预测能力。

| 来源 | 面板用途 | 观测粒度与连接 | 状态与边界 |
| --- | --- | --- | --- |

| UNGA Voting Ideal Points | P1 | 样本国家、美国与中国理想点；ISO3 + 三年窗口 | 计分。2017用2016–2018；2022用2021–2023，后者包含未来一年，只作结构比较。 |

## 重点审计文件

- `data/数据来源登记表.csv`：发布方、来源文件、粒度、连接键、转换、用途、SHA-256和边界。
- `data/字段级来源血缘.csv`：核心、背景、来源年份、转换字段与缺失状态逐列说明。
- `data/各年份数据源覆盖.csv`：按2017/2022目标年列出样本覆盖；CDIS流入/流出分开，未接入来源标为未接入。
- `data/多源数据整合检查.csv`：来源链接、口径、缺失处理和键唯一性的自动检查结果。
- `data/raw/p2/`：2022联盟重建使用的美国国务院原始条约记录、补编和逐国编码表。
- `data/processed/`：各单源已清洗的输入中间表；`data/芯链哨兵_核心面板.csv` 为合并结果。

## 不可混用的解释边界

1. P2是来源年份明确的正式防务安排指标，不是广义安全合作强度；2017与2022来源构造不同，跨年差值需保守解释。
2. UNGA的2022中心窗口包含2023年信息，不能称为严格实时预警或无前视回测。
3. P3只总结所选规则并完成范围核对，没有覆盖BIS全部规则、实体与产品例外；保持在指数之外。
4. CDIS的报告方向、直接对手方和观测年份均保留；有值不等于半导体投资暴露。
5. 表中“覆盖”仅表示来源记录能否连接至研究样本，不表示来源真实性、指数准确率或因果关系已获证明。
