# 芯链哨兵：第三方半导体供应链风险观察

这是“脱钩之后，风险去了哪里？”项目的公开展示仓库。网页用2017年与2022年的12个经济体核心面板，观察中国投入、美国市场、政治位置和供应来源集中度如何在第三方节点重新组合。

## 在线查看

- 打开仓库根目录的 `index.html` 查看总览页。
- 点击页面中的“风险迁移透镜”，或直接打开 `risk-migration-lens.html` 查看单个经济体的跨年变化。
- 点击“企业级扫描”，可用演示数据或本地CSV把国家指标接到企业BOM、供应商和客户清单。
- 网页为静态页面，地图、图表和数据均随仓库提供，不依赖外部接口。

## 目录说明

- `index.html`：风险总览与试点指数排名。
- `risk-migration-lens.html`：单个经济体的2017—2022风险迁移页面。
- `enterprise-scan.html`：企业BOM、供应商、客户与P3人工复核事件的本地扫描原型。
- `assets/`：共享面板数据与示意性世界点阵地图。
- `data/`：核心面板、试点指数和2022年P2补充来源。
- `docs/`：研究报告、数据与方法说明、指标验证报告及报告图表。

## 数据边界

项目使用UN Comtrade、UNGA理想点、ATOP v5.1、OECD TiVA 2025及BIS公开规则等资料。P3法律事件作为政策证据和预警线索，不直接外推为国家级法律分数；2022年P2使用美国国务院公开集体防御安排与北约成员名单，ATOP 2018状态作为交叉资料保留。

网页中的地图是示意性点阵图形，不绘制国界线，不作为国界依据。页面和数据仅用于研究展示，不构成法律、投资或合规意见。

正式参赛文件以项目提交包中的研究报告、数据和方法材料为准。
